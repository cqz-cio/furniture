# 家具导购 Agent 对话框视觉与交互改版设计

日期：2026-07-12
视觉方向：B「高级顾问风」

## 1. 目标

将当前家具导购对话框从通用客服浮层升级为与 RH 风格协调的“高级空间顾问”。改版需要解决顶部按钮重叠、内容层级松散、消息噪声偏多、悬浮图标语义不清、默认位置遮挡页面及拖动体验不完整的问题，同时保留现有大模型、会话恢复、商品推荐和加入购物袋能力。

## 2. 现状审查结论

- 顶部标题过长，与“新对话”和关闭按钮争抢横向空间，在较窄宽度下发生重叠。
- 每条消息重复显示头像、名称和“刚刚”，压缩有效阅读空间。
- `MODEL / PRODUCT-API` 来源单独形成一条消息，打断主要对话节奏。
- 机器人头像更像通用客服，与家具导购和空间设计定位不够匹配。
- 当前默认展开位置依赖悬浮图标位置，容易出现在页面中部并遮挡主内容。
- 拖动后不会吸附边缘；展开和收起之间缺少明确的空间连续性。
- 输入区模式标签、占位文字和发送按钮的层级不够清晰。

## 3. 视觉系统

- 使用深橄榄、暖白、灰褐色，与现有家具站点的克制中性色保持一致。
- 顶部使用深橄榄色品牌面，内容区使用暖白背景；边框保持细且低对比度。
- 主字体沿用站点字体体系；标题使用衬线字体，操作和正文使用无衬线字体。
- 对话框桌面端圆角为 16px，阴影柔和且范围较大，避免厚重黑边。
- 助手主图标采用“沙发轮廓 + 星光”的图标库组合语义；不继续使用手绘机器人图标。

## 4. 桌面端布局

- 默认展开尺寸为约 460 × 660px，并受视口安全边距约束。
- 默认停靠在右下角，距离右侧和底部各 24px。
- 顶部左侧为图标、名称“空间设计助手”和状态“AI 家居顾问 · 随时在线”。
- 顶部右侧仅保留两个 40px 以上点击区域：新对话、收起。
- 消息区占据剩余空间；输入区固定在底部，不随消息滚走。
- 保留八方向缩放，但缩放热区不可遮挡正常按钮和输入区域。

## 5. 展开、收起与拖动

- 悬浮按钮默认位于右下角，尺寸 56px，使用深橄榄背景。
- 首次出现时短暂显示“问问空间顾问”提示，随后自动隐藏。
- 展开时从悬浮按钮附近向上生长，使用轻微缩放和透明度过渡。
- 收起时沿相反方向回到按钮位置；会话内容和会话 ID 保持不变。
- 对话框仅允许通过顶部非按钮区域拖动。
- 拖动结束后吸附到最近的左右边缘，并保持 24px 安全距离。
- 悬浮按钮拖动后同样吸附边缘并持久化位置。
- 遵循 `prefers-reduced-motion`，用户减少动态效果时关闭位移和缩放动画。

## 6. 消息内容设计

- 助手消息使用暖白气泡，用户消息使用深橄榄气泡。
- 连续消息不重复显示头像；普通消息不再显示“刚刚”。
- 欢迎消息下提供三个快捷入口：帮我搭配客厅、按预算选家具、根据图片找同款。
- 快捷入口点击后填充或直接发送对应问题，行为需要明确且可键盘操作。
- 模型回复期间显示三点思考状态；请求完成后自动滚动至最新消息。
- 错误信息保留在消息流中，提供简洁错误说明，并允许用户重新发送。

## 7. 推荐依据与商品卡片

- 模型和商品接口来源合并为“推荐依据”折叠区域，默认收起，不再单独占一条完整消息。
- 商品推荐继续位于对话流中，卡片统一圆角、图片比例和文字间距。
- 商品名称、价格、推荐理由、查看详情和加入购物袋保持可见。
- 多商品继续使用轮播，但按钮点击区域至少 40px，并提供清晰的页码状态。

## 8. 输入区

- 输入区改为一个完整的圆角输入条。
- 左侧显示低强调的当前模式“空间顾问”，中间为输入框，右侧为圆形发送按钮。
- 有文本时发送按钮进入高强调状态；提交期间显示忙碌状态并防止重复提交。
- Enter 发送，输入法组合状态下不误发送；保留可访问标签。

## 9. 移动端

- 小屏幕下对话框变为底部抽屉，占据可用宽度和不超过约 85dvh 的高度。
- 移动端不允许自由拖动和八方向缩放，避免移出屏幕。
- 顶部保留明确的收起按钮和拖动视觉提示，但不实现任意位置拖动。
- 输入区适配安全区域，避免被系统底部区域或软键盘遮挡。

## 10. 可访问性

- 所有图标按钮提供中文 `aria-label` 和悬停提示。
- 交互目标不小于 40 × 40px，保留清晰键盘焦点状态。
- 对话框使用正确的 dialog 语义；展开后焦点进入输入框，收起后焦点回到悬浮按钮。
- 状态更新通过适度的 live region 通知，不重复朗读完整消息列表。
- 颜色不作为唯一状态表达，文字和图标共同说明状态。

## 11. 代码边界

- 核心行为保留在 `FurnitureAssistantPanel.vue`，视觉规则保留在站点样式文件。
- 将重复图标抽成局部可复用图标组件或统一图标映射，避免重复 SVG。
- 不改变后端聊天 API、Redis 会话恢复协议、商品推荐响应结构和购物袋事件接口。
- 不引入与本次改版无关的新页面、账户功能或后台配置。

## 12. 验收标准

- 1365 × 918 桌面视口下，顶部操作按钮无重叠、无遮挡。
- 默认展开位置位于右下安全区域，收起后悬浮图标保持可见。
- 悬浮按钮和对话框拖动后可吸附边缘，刷新后悬浮按钮位置可恢复。
- 新对话、收起、发送、快捷入口、商品轮播和加入购物袋功能正常。
- 历史会话恢复、收起后继续对话和新建会话逻辑不回归。
- 320px 宽度下内容不产生横向溢出，输入区和顶部操作保持可用。
- 单元测试通过，生产构建成功，并完成桌面和移动端截图对比验证。
