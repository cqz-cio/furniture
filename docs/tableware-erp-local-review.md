## 分工权限

| 账号 | 权限范围 |
|---|---|
| 管理员 | 本租户网站、询价和账号/角色管理；不授平台租户管理或全局系统配置 |
| 编辑员 | 产品、文章、图片、资料草稿、预览、提交审核、巡检任务；不能批准或发布 |
| 发布员 | 编辑能力、审核、发布、下线、备份恢复；删除文章前须下线 |
| 询价跟进 | 查看本租户网站询价和记录处理状态；不授网站编辑或客户档案权限 |
| 内容只读 | 浏览网站管理内容；不能修改，不能查看询价联系人 |

餐具目录复用现有页面权限，但不展示只适用于 TRIPEER 的首页编辑菜单。角色权限和菜单都由 ERP 管理，不靠网站界面隐藏按钮来代替后端校验。

## 日常内容流程

1. 在“餐具产品目录”或“文章管理”编辑并保存草稿，检查私密预览。
2. 提交对应内容版本，发布员在“网站运营中心”批准，再单独发布。
3. 图片从 ERP 素材库选取。餐具 PDF 使用运营中心的私有文件上传；审批前可由登录审核员下载检查，通过后才出现在公开资料中心。
4. 已发布内容与草稿分离；资料过期、下线后停止公开下载。修改、历史恢复或备份恢复后必须重新审核。
5. 网站询价经服务端固定绑定本租户，进入 ERP 的“询盘汇总”。当前仅本地入库，邮件和站内通知关闭。

## 本地运行与维护

专用启动器 `scripts/tableware-local-runtime.py start|stop|status` 运行本 checkout 的完整 ERP，并记录 PID、日志与有界就绪检查。它使用仓库 Java 17 解析器，不接管 `D:\code` 的分支快照运行时。

网站使用原 `website/trendzgreen-homepage/scripts/start-local-preview.py --erp`。完整 ERP 配置在 `work/phase4-erp-integration/connection-private.json`；缺配置或上游失败不会悄悄回落成旧模拟数据。

`scripts/provision-tableware-local.py` 只允许本机固定端口和独立联调库；重复配置保留密码，不重置已有账号。`scripts/import-tableware-cms.py --execute` 从已核验的本地源导入；不带参数时只准备图片材料，不写 ERP。

完整运行数据在 MySQL 中。运营“内容备份”不包含整个数据库、账号、询价或文件字节，不能代替一致的数据库备份。
