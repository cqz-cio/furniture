# 官网租户素材库

V053 为 TRIPEER 品牌运营增加“网站管理（CMS）→ 素材库”，保留原有 CMS、询盘和访问数据权限。新增权限为 `seo:media:query/upload/update/archive`。不授予全局 `infra:file:*`，不创建账号或修改密码。

素材管理支持 JPG、PNG、PDF，单文件最多 10 MiB；图片最大边长 12000 像素且总像素不超过 2500 万。服务端按实际内容检查文件，将图片重新编码以移除额外内容，PDF 必须可解析、未加密且为 1–1000 页。浏览器 MIME 不是判断依据。

素材元数据保存于带 tenant_id 的 `website_media`；查询、改名、移出与恢复均检查当前租户。二进制复用现有文件存储，路径包含服务端确定的租户编号和随机标识，重复文件名不会覆盖已有图片。这里用于公开网站素材，不用于内部文件或应聘简历。

首页“页面内容”中的图片字段可打开素材选择器。选择图片后带入地址和图片说明，保存草稿、预览、发布流程不变；上传本身不会修改官网。已有页面 JSON 字段保持不变，保存或发布托管素材地址时还会核对素材归属与图片类型，不能通过复制另一租户的素材地址或 PDF 地址绕过选择器。

“移出”仅改变素材库可选状态，可以恢复。已发布页面和历史版本引用的公开文件保留；本功能不永久删除二进制文件，也不自动替换已发布图片。

## 公开访问地址

日常 CD 从经过验证的发布配置生成 `ERP_PUBLIC_API_URL`，通过 Compose 提供 `YUDAO_WEBSITE_MEDIA_PUBLIC_BASE_URL`。数据库文件存储返回的内部 `/admin-api/infra/file/...` 地址，仅在匹配本租户托管路径时转换成公开 ERP 域名。其他外部存储仅接受稳定 HTTPS 地址。

本地单独启动 ERP 时设置 `YUDAO_WEBSITE_MEDIA_PUBLIC_BASE_URL` 为实际可访问的 ERP API 原点，例如本地后端地址；该变量是公开配置，不是密钥。未配置时上传明确报错。生产公开地址使用 HTTPS；官网仅在自身为 HTTP 的测试环境接受经过后端归属校验的 HTTP 托管图片路径。

## 验证与后续范围

后端测试覆盖租户拦截器、操作权限、文件格式/大小、文件路径唯一性、公开地址转换、素材移出恢复、PDF 限制和首页发布引用。部署前继续执行隔离数据库迁移及恢复演练，使用实际发布镜像验证 Flyway；按测试、生产预检、生产 CD 顺序发布。

首个图片选择器接入首页首屏。新闻封面和其他页面可复用同一组件，但本次不扩展这些页面与官网前端的 CMS 接入。素材目录、批量上传、永久删除、配额和 CDN 缩略图属于后续独立需求。
