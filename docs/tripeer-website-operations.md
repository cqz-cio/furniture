# TRIPEER 官网运营权限

V052 在现有 TRIPEER `brand_operator` 和独立租户套餐上增加询盘汇总、数据看板，以及三个明确的权限：

- `crm:clue:query`：查看本租户官网询盘和处理汇总。
- `crm:clue:triage`：处理本租户官网询盘、记录跟进；不提供 CRM 所有者权限。
- `statistics:website:query`：只读官网访问数据。

已有 26 项 CMS 权限保留。迁移不创建账号、不改密码、不复制其他环境的用户，不授予客户档案、报价、导出、利润、共享文件或系统设置权限。现有绑定这个角色的账号在重新登录后获得新菜单。

后端同时检查询盘是网站提交记录、属于当前租户以及操作属于读取或跟进级别。删除、转化客户等所有者操作继续拒绝；官网运营新增跟进时不能通过关联联系人或商机 ID 修改销售数据。跟进记录入口复用既有组件，官网询盘详情不提供删除按钮。

`/admin-api/statistics/website/summary` 和 `/trend` 使用独立权限，查询固定为站点范围，并通过明确字段白名单返回首页 PV/UV、日期和数据覆盖状态；不会返回订单、销售额、成本、利润或对比数据。原有电商看板权限及接口保持原样。官网运营视图隐藏报价清单、商品和销售指标，日趋势使用服务端已有的首页 PV。

部署前对 V051 数据库的独立副本执行 V052，核验其他租户、账号与内容不变，演练备份恢复；再使用实际 CI 镜像执行 Flyway 迁移和旧版本兼容校验。按测试 CD、生产预检、生产 CD 顺序发布。

## 接入边界

本次开放 ERP 运营能力，未开启 TRIPEER 官网目前禁用的咨询表单，也未新增访问数据采集。无采集数据时看板显示不可用提示，不能把历史空数据当作真实零访问量。

共享文件管理使用全局 `infra_file`，不直接授予官网运营。独立租户素材库仍是后续功能。询盘邮件沿用现有租户配置；运营可查看状态，管理员配置接收和发送渠道，本次不新建邮件服务或自动发送通知。
