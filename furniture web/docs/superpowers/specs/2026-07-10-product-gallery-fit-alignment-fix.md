# 商品详情页主图适配与对齐修复

## 目标

解决商品详情页主图被裁掉、主图与缩略图栏宽度不一致的问题，让所有商品详情页完整展示家具主体。

## 根因

- 主图容器同时使用固定高度和 `4 / 3` 比例，实际宽度收缩为 693px，而缩略图栏保持 766px，导致两者错位。
- 主图图片在网格内以 `width: 100%; height: 100%` 参与尺寸计算，实际高度按素材比例变为 866px，随后被 520px 高的容器裁掉。
- 展示素材上下预留了大面积空白，适合以居中裁切的方式突出家具主体。

## 统一规则

- 主图容器宽度固定为所在详情页左栏的 100%，不再使用 `4 / 3` 约束宽度。
- 桌面端继续使用 420-520px 的响应式高度；移动端继续使用 360px。
- 主图图片绝对铺满容器，使用 `object-fit: cover` 和居中定位；素材上下空白会被裁掉，但家具主体完整保留。
- 缩略图栏继续使用左栏的完整宽度，因此与主图左右边缘完全对齐。
- 规则只修改共享的商品画廊样式，对全部 `SofaPdpPage.vue` 商品详情页生效。

## 验证标准

- 桌面端主图和缩略图栏宽度相同，左右边缘对齐。
- 主图图片的渲染高度不超过容器高度，不再被 `overflow: hidden` 截断。
- Oak Nightstand 和 Walnut Single Sofa 均能完整显示家具主体。
- 移动端仍为单栏、360px 主图且没有横向滚动。
