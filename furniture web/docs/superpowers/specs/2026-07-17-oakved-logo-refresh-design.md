# Oakved 家居前端新版 Logo 替换设计

## 目标

将家居商城前端中所有 Oakved 旧版品牌 Logo 更新为用户提供的 2026-07-16 新版字标，在首页图片背景、普通白色页面、移动菜单、购物车和结算页中保持清晰可见。

## 资产策略

- 使用用户提供的白色文字 PNG 作为唯一品牌母版，不进行 AI 重绘，确保字形完全保持原稿。
- 原文件已经包含透明 Alpha 通道，无需再次抠图。
- 裁掉大面积多余透明边距，并缩放到满足高像素密度屏幕的 Web 合理尺寸，降低浏览器解码内存和传输负担。
- 项目只引用一个新版白色透明 Logo 资产；不再依赖旧版黑白两套图形。

## 场景适配

- 首页主视觉、图片卡片和其他深色背景：直接显示白色 Logo。
- 白色或浅色背景（普通页头、移动菜单、购物车、结算页）：通过 CSS `filter` 将同一白色资产显示为黑色。
- 首页覆盖式页头：默认显示白色；悬停、聚焦或展开菜单切换到浅色背景时显示黑色。
- 保持 Logo 原始宽高比，不拉伸；只按各组件已有尺寸规则调整显示宽度。

## 修改范围

- 替换 `public/assets/brand` 下的品牌 Logo 资产。
- 更新 `RhHeader`、`HomePage`、`BrandEyebrow`、`CartDrawer`、`CheckoutPage` 中的全部 Oakved Logo 引用。
- 更新相关 CSS 的黑白场景过滤规则和必要的尺寸约束。
- 搜索整个 `src`、`public` 和入口 HTML，确认没有遗留旧版 Logo 引用。

## 验证

- 自动检查输出 PNG 具有 Alpha 通道、四角完全透明、可见内容边界合理。
- 运行 Logo 引用测试，确保全站只引用新版统一资产，并覆盖白色与黑色显示场景。
- 运行前端测试和生产构建。
- 启动本地页面，检查首页桌面端和移动端，以及至少一个浅色背景场景，确认 Logo 清晰、比例正确且无白底矩形。

## 不在范围内

- 不修改 Logo 字形、文案或颜色设计。
- 不更换非 Oakved 的系列、认证或合作品牌 Logo。
- 不改动商城其他视觉布局或业务逻辑。
